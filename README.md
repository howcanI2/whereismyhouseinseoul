# 서울 내집마련 전략판

구로 오류동에서 광화문으로 출퇴근하는 27세 기준으로, 예산에 맞는 서울 아파트를 지도에서 찾고 대출·로드맵을 보는 앱입니다.

- **지도**: 구 → 법정동 → 행정동 → 단지 단위로 가격 변화, 평당가, 내 예산 비중, 거래량 변화, 전세가율을 봅니다. 지하철 노선과 재개발·정비구역 레이어가 있습니다.
- **내 돈**: 예산 시나리오, 대출 계산기, 주담대 금리 흐름, 대출 시장 현황.
- **할 일**: 3년 로드맵과 알아둘 정책.

## 실행

```bash
cd app
npm install
npm run dev
```

`npm run build`는 JS·CSS가 모두 들어간 `dist/index.html` 하나를 만듭니다. 데이터는 `app/public/data/*.json`에서 불러옵니다.

## 데이터 출처 (2026-10-27 스냅샷)

- 국토교통부 아파트 매매·전월세 실거래 (real-estate MCP)
- 한국은행 ECOS 가중평균금리, 은행연합회·언론 보도 (금리·대출 현황)
- 서울 열린데이터광장 정비사업 현황 (OA-23112, OA-23113)
- 통계청 구 경계, 도로명주소 법정동 경계 (southkorea/seoul-maps), 행정동 경계 (vuski/admdongkor)
- 지하철 노선: OpenStreetMap 기여자 (ODbL)
- 단지·역 좌표: 카카오 로컬 검색

예산과 통근 시간은 추정치이며 투자 조언이 아닙니다.
