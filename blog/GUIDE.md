## 2. 클릭되는 제목 만드는 법

블로그 SEO 글들이 공통으로 권하는 것 ([라이브클래스](https://www.liveklass.com/story/blog-seo-title), [브런치](https://brunch.co.kr/@accouting2040/27), [구글 제목 가이드](https://developers.google.com/search/docs/advanced/appearance/good-titles-snippets?hl=ko)):

1. **검색어를 맨 앞에**: "서울 아파트 신고가…"처럼 사람들이 치는 말로 시작합니다.
2. **숫자 하나**: TOP10, +29.6%, 7억, 11월 1주. 정리된 글이라는 신호가 됩니다.
3. **구체적인 이름 하나**: 단지명·동 이름은 그 동네 사람이 검색합니다(롱테일).
4. **질문 또는 대비**: "어디서 신고가가 나올까?", "강남 -0.5%, 중랑 +6.5%".
5. **짧게**: 모바일 검색 결과에서 앞부분만 보입니다. 중요한 말은 앞 25자 안에 넣습니다.
6. **하지 말 것**: "폭락", "무조건" 같은 과장, 같은 키워드 반복, 데이터에 없는 숫자. 사이트 신뢰가 무너지면 광고 수익도 같이 떨어집니다.

제목 공식 (초안이 자동으로 만들어 줍니다. 편집 메모 댓글에 후보 3개가 있습니다):

| 공식 | 예 (이번 주 데이터) |
|---|---|
| 검색어 + TOP N + 시점 \| 단지 + 수치 | 서울 아파트 신고가·급매 TOP10 (11월 1주) \| 망원동 영화블렌하임 +29.6% |
| 질문형 + 시점 | 서울 아파트, 지금 어디서 신고가가 나올까? 11월 1주 실거래 정리 |
| 대비형 | 강남 -0.5%, 중랑 +6.5%… 서울 25개 구 가격 변화 (8~10월) |
| 예산형 | 6억으로 서울 84㎡ 살 수 있는 동네 5곳 (최근 6개월 실거래) |
| 지역 롱테일 | 망원동 영화블렌하임 신고가 12억 7천, 직전 최고가보다 29.6% |

## 3. 글 틀

```
제목        검색어 앞 · 숫자 · 시점 · 구체 이름
도입 2줄     숫자로 된 대비 ("신고가 2,940건 vs 급매 34건") + 이 글에서 무엇을 보여주는지
3줄 요약     바쁜 사람은 여기서 끝나도 되게
✍️ 내 의견   한두 줄, 내 말투로 (이 줄이 있어야 '복붙 글'이 아니라 내 글이 됩니다)
소제목 1~3   질문형 ("급매는 어디에?") + 표 + ※ 기준 설명
더 보기      whereismyhouse.kr 링크 + "지도에서 ○○구 → ○○동 누르면…" 안내
출처         국토교통부 실거래가 공개시스템 등, 기준일
태그         #서울아파트 #신고가 #급매 … + 이번 주 구·동·단지 (최대 30개)
```

- 사진: 네이버는 이미지가 있는 글을 선호한다는 게 업계 통설입니다. 사이트 지도 화면 캡처 1~2장을 소제목 사이에 넣으세요.
- 길이: 표 3개 + 설명이면 충분합니다. 글자 수를 억지로 늘리지 마세요.
- 네이버와 티스토리에 **똑같은 글**을 올리면 둘 중 하나가 중복 문서로 밀릴 수 있습니다. 한쪽은 제목·도입·의견을 바꿔 올리세요.

## 4. 매주 할 일 (10분)

1. 월요일 08시 Issue 확인 → 댓글의 **제목 후보**와 **네이버 키워드 리포트**를 봅니다.
2. 리포트에서 지난주보다 오른 키워드가 있으면 제목이나 도입 문장에 넣습니다. 상위 글 제목 패턴(숫자·질문형 비율)도 참고합니다.
3. ✍️ 줄을 채우고, 렌더링된 Issue 본문을 복사해 붙여 넣습니다. 태그 줄은 태그 칸으로 옮깁니다.
4. 매주 같은 요일에 발행합니다. 시간대는 리포트가 몇 주 쌓이면 조회수를 보고 정합니다.
